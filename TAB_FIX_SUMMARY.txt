# ✅ TAB FIX - RED UNDERLINE ISSUE RESOLVED

## 🔴 THE PROBLEM (From Your Screenshots)

**What you reported:**
- Both tabs showed the red underline
- When switching to "DISK IMAGES" tab, the red underline was still also on "FORENSIC ARTIFACTS"
- The red indicator should ONLY appear on the currently active tab

**What was causing it:**
- Inline CSS style: `style="border-bottom:2px solid var(--accent)"` was hardcoded on the first button only
- This prevented the JavaScript from properly toggling the active class
- Both tabs appeared to be selected simultaneously

---

## ✅ THE FIX (Applied)

### **1. Removed Inline Styles**
**Before:**
```html
<button class="inv-tab active" onclick="switchUploadType('artifacts', this)" 
        style="border-bottom:2px solid var(--accent)">
  🗄️ Forensic Artifacts
</button>
<button class="inv-tab" onclick="switchUploadType('diskimage', this)">
  💾 Disk Images
</button>
```

**After:**
```html
<button class="inv-tab tab-button active" onclick="switchUploadType('artifacts', this)" 
        data-tab="artifacts">
  🗄️ Forensic Artifacts
</button>
<button class="inv-tab tab-button" onclick="switchUploadType('diskimage', this)" 
        data-tab="diskimage">
  💾 Disk Images
</button>
```

**Why:** Removed the hardcoded `style` attribute that was preventing CSS from working

### **2. Added Dedicated CSS for Tab Buttons**
```css
/* ── TAB BUTTONS (Upload Type Tabs) ──────────────────────── */
.tab-button {
  font-family: 'Share Tech Mono', monospace;
  font-size: .65rem;
  letter-spacing: .1em;
  text-transform: uppercase;
  cursor: pointer;
  padding: .45rem .85rem;
  color: var(--text3);
  border: none;
  border-bottom: 2px solid transparent;  /* ← Starts transparent */
  background: none;
  transition: all .15s;
}

.tab-button:hover {
  color: var(--text2);
}

.tab-button.active {
  color: var(--accent2);
  border-bottom-color: var(--accent);   /* ← Only shows when active */
}
```

**Why:** CSS now controls the red underline appearance based on the `active` class

### **3. Fixed JavaScript Function**
**Before:**
```javascript
function switchUploadType(type, btn) {
  document.querySelectorAll('.upload-type-panel').forEach(p => p.classList.remove('active'));
  const panel = document.getElementById(`uploadType-${type}`);
  if (panel) panel.classList.add('active');
  
  // This was selecting wrong elements
  document.querySelectorAll('[onclick*="switchUploadType"]').forEach(b => b.classList.remove('active'));
  if (btn) btn.classList.add('active');
}
```

**After:**
```javascript
function switchUploadType(type, btn) {
  // Remove active from ALL panels
  document.querySelectorAll('.upload-type-panel').forEach(p => p.classList.remove('active'));
  // Remove active from ALL tab buttons
  document.querySelectorAll('.tab-button').forEach(b => b.classList.remove('active'));
  
  // Show selected panel
  const panel = document.getElementById(`uploadType-${type}`);
  if (panel) panel.classList.add('active');
  
  // Activate clicked button
  if (btn) btn.classList.add('active');
}
```

**Why:** Now properly removes the `active` class from all tab buttons before adding it to the clicked one
