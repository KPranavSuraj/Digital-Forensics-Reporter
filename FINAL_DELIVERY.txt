## ⚡ Quick Start (10 Minutes)

```bash
# 1. Extract
unzip Digital-Forensics-Reporter-Complete.zip
cd Digital-Forensics-Reporter-Complete

# 2. Install
cd backend

# Edit .env with your API key

# 4. Run
```
