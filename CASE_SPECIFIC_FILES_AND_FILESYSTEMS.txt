## 🧠 HOW THE VALIDATION WORKS

### **Step 1: Detect Case Type**
When you create a case, the system detects the case type:
```
Case Name: "Dark Web Investigation"
→ Recognized as: DARK WEB case
→ Keyword detected: "dark web"

Case Name: "Insider Threat Analysis"
→ Recognized as: INSIDER THREAT case
→ Keyword detected: "insider threat"
```

### **Step 2: Check File Name**
When you upload a file, the system checks if it matches:
```
Case: DARK WEB
Upload: operation_dark_web.dd
→ Contains "dark_web" keyword ✓
→ ALLOWED ✅

Case: DARK WEB
Upload: operation_insider_threat.dd
→ Does NOT contain "dark_web" keyword ✗
→ REJECTED ❌
Error message: "File mismatch! 'operation_insider_threat.dd' is not for 'Dark Web' case."
```

### **Step 3: Upload or Reject**
- ✅ If file matches → Upload succeeds
- ❌ If file doesn't match → Upload rejected with clear error

## 📞 TROUBLESHOOTING

### **"File mismatch" error**
**Problem:** Uploading wrong file for case
**Solution:** Check case name matches file keywords
- Dark Web case: use `dark_web_*..*` files
- Insider Threat case: use `insider_threat_*..*` files

### **pytsk3 not detecting filesystem**
**Problem:** Using old disk images without filesystems
**Solution:** Download latest ZIP with new disk images

### **Case name not recognized**
**Problem:** Case name doesn't match keyword pattern
**Solution:** Include "dark web" or "insider threat" in case name
- Dark Web: Include "dark web" or "dark_web"
- Insider Threat: Include "insider threat" or "insider_threat"
