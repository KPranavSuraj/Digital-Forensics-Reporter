### **Common Issues**

**"ModuleNotFoundError: No module named 'pytsk3'"**
```bash
pip install pytsk3
# On Linux, first: sudo apt-get install libtsk-dev
# On macOS, first: brew install sleuthkit
```

**"Method Not Allowed" (405) error**
```bash
# Make sure you're using POST method:
curl -X POST http://localhost:8000/api/upload ...
# Not GET:
curl http://localhost:8000/api/upload ...
```

**Disk image upload zone not showing**
- Click the "💾 Disk Images" tab
- Should display upload zone
- If not, refresh page (Ctrl+R or Cmd+R)

**Red underline on both tabs**
- This is fixed! Extract latest ZIP
- Red line should only appear on active tab
- Clicking tabs switches which one has red line
