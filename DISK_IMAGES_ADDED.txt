## 🚀 HOW TO USE

### **Quick Test (1 minute)**

```bash
# Start server
cd backend
python main.py

# In new terminal, upload disk image
curl -X POST http://localhost:8000/api/upload \
  -F "file=@sample_data/operation_dark_web.dd" \
  -F "case_name=Dark Web Test" \
  -F "analyst_name=Tester"

# Should show: "file_type": "disk_image"
```

### **Web Interface Test (3 minutes)**

1. Open `http://localhost:8000`
2. Click "💾 Disk Images" tab
3. Drag `operation_dark_web.dd` to upload zone
4. Click "⚡ Analyze Disk Image"
5. Watch pytsk3 analyze the image
6. View the forensic report

### **Test All Formats (10 minutes)**

```bash

    -F "file=@sample_data/operation_dark_web.$format" \
    -F "case_name=Test $format" \
    -F "analyst_name=Tester"
done
```
